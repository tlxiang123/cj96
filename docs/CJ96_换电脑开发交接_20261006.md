## 六、迁移工具使用说明

文件：D:/Install/FlyThingsIDE/bin/workspace/cj96/tools/cj96_migration.py

直接用 Python 运行，不带参数：显示必要目录是否存在和本地源版本，不连接板子，不写工程。

参数：
- --report 目标JSON文件：保存当前环境检查报告（不读取秘密内容）。
- --pack 目标ZIP文件：完整保存当前主工程，包括 .git、未提交/未跟踪文件、Release 和诊断；不包含工程外的 SDK/IDE/AC/DC/APP。目标必须在工程目录以外，且不能已存在。目录很大时可能花较长时间。
- --verify ZIP文件：读取包内 SHA-256 清单并逐文件验证，不解压、不执行包内代码。

打包前关闭 IDE 和其他修改进程。工具遇到链接、读取失败或检测到文件变化会报错，不会声称打包成功。ZIP 不是加密包；失败留下的 .partial 不能作为完成包使用。工具不会自动提取或覆盖新电脑工程。
